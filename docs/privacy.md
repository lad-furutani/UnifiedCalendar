# プライバシーポリシー

UnifiedCalendar（以下「本アプリ」）における利用者データの取扱いを定めます。

## 提供者

Logic and Design Inc.

## 本アプリの性質

本アプリは利用者の Windows 端末上で動作するデスクトップアプリケーションです。**提供者が運営するサーバーは存在せず、利用者のデータが提供者へ送信されることはありません。**

## 取得する情報

利用者が接続を許可した Google アカウントおよび Microsoft 365 アカウントから、次の情報を**読み取り専用**で取得します。

- カレンダーの一覧（名称、色）
- 予定の情報（件名、開始・終了日時、終日かどうか、場所、説明、参加状態、色、会議リンク、元の予定へのリンク、キャンセル状態）
- アカウントの表示名とメールアドレス（どのアカウントの予定かを区別するため）
- タイムゾーン設定（Microsoft 365 のみ。予定の時刻を正しく表示するため）

**予定の作成・変更・削除は行いません。** 要求する権限は読み取りに限定されています。

| サービス | 権限 |
| --- | --- |
| Google | `https://www.googleapis.com/auth/calendar.readonly` |
| Microsoft 365 | `Calendars.Read`、`MailboxSettings.Read` |

## 利用目的

取得した情報は、**本アプリの画面に予定を表示するためだけ**に使用します。他の目的には使用しません。

## 保存場所

取得した情報と認証情報は、**すべて利用者の端末内にのみ**保存します。

```
%LOCALAPPDATA%\UnifiedCalendar
```

- **アクセストークンは Windows の DPAPI により暗号化**して保存します。復号できるのは、そのトークンを保存した Windows ユーザー本人だけです。
- 予定のキャッシュ、アプリの設定、動作ログも同じ場所に保存します。
- **動作ログには、予定の件名・場所・説明・URL・メールアドレス・トークンを記録しません。**

## 第三者への提供

**行いません。** 本アプリの通信先は Google および Microsoft の各 API のみです。アクセス解析、広告、利用統計の送信は一切ありません。

## 権限の取り消しとデータの削除

**サービス側で権限を取り消す**

- Google: <https://myaccount.google.com/permissions>
- Microsoft: <https://myapps.microsoft.com>

**アプリから削除する**

設定画面でアカウントを削除すると、そのアカウントの認証情報が端末から削除されます。

**すべて削除する**

本アプリをアンインストールしたうえで、`%LOCALAPPDATA%\UnifiedCalendar` フォルダーを削除してください。**アンインストールではこのフォルダーは削除されません**（再インストール時に設定を引き継ぐためです）。

## Google API から取得した情報の取扱い

本アプリが Google API から受け取る情報の使用および転送は、限定的使用（Limited Use）の要件を含む [Google API サービスのユーザーデータに関するポリシー](https://developers.google.com/terms/api-services-user-data-policy)に準拠します。
